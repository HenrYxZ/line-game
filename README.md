# 10 de 10

Puzzle game made in Python with pudu-ui and pyglet

![screenshot](docs/imgs/screenshot.png)


# Usage

## Install dependencies

You will need to install *uv* first ([here](https://docs.astral.sh/uv/)).

Then you can do

`$ uv sync`

## Run it

`$ uv run main.py`


# Objective

There is one order in which all the squares have to be, but you don't know which order it is.

You only know *how many* of the squares are in their place, but you don't 
know *which of them* are.

You need to move them until 10 out of 10 (all) are in order.


# Controls

To swap between two squares, you need to select one and then the other.

- LEFT CLICK - Select an item

- ARROW KEYS - Move focus

- SPACE or ENTER - Select the focused item

- ESC - pause the game or go back to menu. 


# Dependencies

It requires Python >= 3.13

- pudu_ui v0.2.2
- pyglet v3.0.dev3
